# Task 4 - Basic Chatbot

## Objective

Build a simple rule-based chatbot using Python.

## Project

This project is a basic chatbot that responds to predefined user messages.

## Supported Messages

- `hello` → `Hi!`
- `how are you` → `I'm fine, thanks!`
- `bye` → `Goodbye!`

For other messages, the chatbot displays a message saying that it does not understand.

## Concepts Used

- `if-elif-else`
- Functions
- `while` loop
- User input
- Output
- String methods

## How to Run

1. Make sure Python is installed.
2. Run the program:

```bash
python task4.py
```

3. Enter messages when prompted.
4. Type `bye` to end the chatbot.

## Example

```text
Basic Chatbot
Type 'hello', 'how are you', or 'bye'.

You: hello
Bot: Hi!

You: how are you
Bot: I'm fine, thanks!

You: bye
Bot: Goodbye!
```
